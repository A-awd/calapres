# Migration Source Index

This index records source classes used to build the sanitized foundation; it does not copy source contents.

## Approved sources

- The final One Brain canonical registry, repository plan, unification plan, naming map, and sensitive-data exclusions.
- Existing calapres GitHub code, documentation, branches, and Git history.
- Sanitized project facts reconciled by the migration discovery inventories.

## Excluded sources

- Raw Claude, ChatGPT, Codex, or Hermes conversations.
- Credentials, session material, customer and order records, and unsanitized platform exports.
- Unverified local copies that have not been reconciled with GitHub.

## Reconciliation rule

The latest approved GitHub state is authoritative. New information may enter only after sanitization and an explicit repository update.
