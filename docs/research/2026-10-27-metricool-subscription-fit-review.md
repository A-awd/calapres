## Public plan implications

The executing agent read [Metricool's official pricing and plan guidance](https://metricool.com/pricing/).
The public Advanced tier includes API access; Starter does not include API access. Reducing to
a tier without API can therefore remove eligibility needed by the approved Metricool read
integration. A working read-only allowlist does not preserve paid-feature eligibility after a
downgrade, and an existing connection alone does not justify retaining a subscription.

The public Free tier supports one brand. Cancellation or downgrade takes effect at the end of
the current billing cycle according to the provider guidance; paid benefits remain until that
boundary. These are plan/transition implications, not a cancellation, downgrade, retention
or data-deletion guarantee for every account object. Review the actual confirmation and effects
before a commercial change, and preserve required records without deleting brands to fit a tier.
