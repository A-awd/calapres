# Address alternatives: not locked to Onwan — 2026-10-29

## Scope and conclusion

The owner asked whether the native address path is blocked and whether Onwan is compulsory.
Current primary-source research confirms other Shopify apps exist, but this review found no
verified replacement that proves all three requirements on the current store: valid short-code
lookup, full native shipping-address fill, and correct automatic OTO destination fields/update.
This is a bounded research result, not a claim no such product or official solution exists.

The prior genuine Onwan-origin write already saved a full native Shopify address. OTO's partial
update/field mapping remains a separate observed defect. Changing address apps alone does not
prove this connector defect disappears. A vendor's App Store Works with OTO statement is a useful
lead, not proof of a jointly supported configuration or acceptance on this account.

## Verified candidates and limitations

### Enwany (a different app from Onwan)

Shopify App Store names Rafik Adel as developer and lists OTO, Torod and iCarry under Works with.
The publisher's own explanation supports all Shopify plans without checkout extensions and
starts after order creation: derive a short code from the shipping address already entered.
Its privacy policy specifies HERE geocoding, order metafield storage and optional notes/tags.
The official settings screenshot offers appending the code to Shipping Address Line2.
WhatsApp recovery is optional and can be disabled according to privacy sections3/7.

This is not documented proof of the owner's requested code-first full-address-fill experience.
No OTO-side source/update contract proving all structured fields or post-import updates was
found. If existing addresses are ambiguous, successful automatic recovery cannot be promised.
The public App Store developer address is Cairo; a Saudi contracting/invoice entity was not
verified. No commercial approval or installation follows from this research.

Sources:
- https://apps.shopify.com/enwany
- https://scalecomm.net/enwany
- https://enwany-app-production.up.railway.app/privacy

### Saudi Address Pro

Its App Store listing expressly describes entering a short code, SPL validation and full address
autofill through a checkout widget. This fits the first two desired capabilities as a publisher
claim. The listing does not prove the current Basic-plan path or OTO's structured field reading.
Shopify's own documentation reserves UI extensions in checkout information/shipping/payment
steps for Plus, while thank-you/order-status extensions are available on Basic. Therefore do
not market this app as a confirmed Basic solution or recommend a plan upgrade as a tested fix.

Sources:
- https://apps.shopify.com/saudi-address-pro
- https://help.shopify.com/en/manual/checkout-settings/customize-checkout-configurations/checkout-apps

### Zoketo — lead withheld from ready shortlist

A publisher article dated23February describes pre-checkout short-code/SPL lookup and address
prefill on all plans. The current app/site positioning focuses on OTP login/popups, and its FAQ
says new customer accounts are incompatible, requesting legacy accounts. Current feature
availability and the address feature's pricing are not confirmed. Do not change customer
accounts or install it based on the historical article. OTO transfer is unproved.

Sources:
- https://zoketoapps.com/en/blogs/news/short-address-code-shopify-saudi-arabia
- https://apps.shopify.com/zoketo-otp-login-with-phone
- https://zoketoapps.com/

## Recommendation and next gate

Onwan is replaceable; retain its current Free state rather than wait on a paid subscription.
Evaluate alternatives against an explicit native OTO field/update contract and the full required
customer journey. Do not claim Enwany's reverse-direction resolution meets code-first capture.
Obtain evidence of the exact supported Basic/new-accounts path and correct OTO mapping before
any new commercial decision or separately approved bounded test. No new test is justified merely
by another app's listing. No need to repeat the historical fixtures without a concrete change.

OTO's public API documents short-code resolution and native address fields, but API capability
is not evidence that the existing Shopify connector performs those mappings. No new API/channel,
key, backend or middleware is proposed for deployment under this review.
