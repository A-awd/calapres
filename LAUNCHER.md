# Launcher Protocol

Claude, Codex, ChatGPT, Hermes, and future agents are interchangeable launchers. None is a source of truth. GitHub is the permanent source of truth.

## Launch

1. Open this repository.
2. Inspect the latest GitHub branch and commit state.
3. Read AGENTS.md, STATE.md, HANDOFF.md, and relevant DECISIONS.md entries.
4. Read README.md and only the project files needed for the task.
5. Apply global ai-operating-system rules without moving calapres memory into that repository.

## Synchronize

Before ending meaningful work, update STATE.md and HANDOFF.md, record decisions when needed, and commit and push when authorized. If local or platform memory conflicts with approved GitHub content, GitHub wins unless an authorized decision documents a replacement.
