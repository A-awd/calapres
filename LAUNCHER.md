# Launcher Protocol

Canonical project: `calapres`
Canonical repository: `A-awd/calapres`
Default branch: `main`
Current approved One Brain foundation ref: `migration/one-brain-foundation`

Claude, Codex, ChatGPT, Hermes, and future agents are interchangeable launchers. GitHub is the only permanent authority; platform memory and chat are non-authoritative.

## Before work

1. Open the canonical repository and verify its remote.
2. Inspect the working tree, current branch, latest local commit, latest GitHub commit, and synchronization state.
3. Refresh through an authorized mechanism and continue only from the latest verified GitHub state.
4. Read `README.md`, `AGENTS.md`, `STATE.md`, `HANDOFF.md`, `DECISIONS.md`, and `LAUNCHER.md`.
5. Read relevant linked decisions, workflows, and security guidance.
6. Use `A-awd/ai-operating-system` only for global rules.
7. Confirm scope, protected data, blockers, and the next authorized action before implementation.

## After meaningful work

1. Validate and review the exact change.
2. Update `STATE.md` and `HANDOFF.md`.
3. Update `DECISIONS.md` when a durable decision was made.
4. Record blockers, risks, and unfinished or unpushed work.
5. Commit and push when authorized, then verify the remote revision.
6. Do not claim durable completion if GitHub does not contain the reported state.

Never expose restricted data. Never leave GitHub behind the conversation.
