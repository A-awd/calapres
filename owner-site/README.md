# Calapres ownership page

This directory contains the isolated static ownership page intended for
`awd-businesses.com`.

The site is deployed independently from the Shopify theme through
`.github/workflows/deploy-owner-site.yml`. The custom domain is connected only
after the generated GitHub Pages site is verified.

The page exists to make the relationship between Calapres and the verified
legal entity explicit, visible, and machine-readable without changing the
Shopify theme.
